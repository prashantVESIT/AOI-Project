## 📖 About

**AirIndx** is a sleek, modern, and fully responsive web application that delivers **real-time Air Quality Index (AQI)** data, live weather conditions, and detailed pollutant breakdowns for any city on Earth.

Powered by the **OpenWeather API** and **World Air Quality Index (WAQI) API**, AirIndx transforms raw environmental data into a clean, glanceable dashboard — complete with a live global AQI map, trend charts, and personalized health recommendations.

Whether you're planning your day or tracking pollution patterns, AirIndx gives you the numbers that matter, at a glance.

## ✨ Features

| Category | Highlights |
|---|---|
| 🌍 **Global Search** | Instantly search AQI data for any city worldwide |
| 📊 **Live AQI** | Real-time Air Quality Index with color-coded severity |

| 📈 **Trend Charts** | Interactive AQI history powered by Chart.js |

| 🕒 **Live Clock** | Real-time date & time display |
| 💾 **Search History** | Recently searched cities saved locally |
| 📱 **Fully Responsive** | Seamless experience across all devices |

## 🚀 Getting Started

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/prashantVESIT/AOI-Project.git
```

### 2️⃣ Open the Project
Open the folder in **Visual Studio Code** (or your editor of choice).

### 3️⃣ Configure API Keys
Create a `.env` file in the project root:

```env
OPENWEATHER_API_KEY=YOUR_OPENWEATHER_API_KEY
WAQI_API_KEY=YOUR_WAQI_API_KEY
```

> ⚠️ **Note:** This project currently makes API requests directly from the frontend. For production deployments, route requests through a backend to keep your API keys secure.

### 4️⃣ Run It
Simply open `index.html` in your browser, or serve it with your favorite local dev server.
